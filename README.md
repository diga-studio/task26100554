# Sentinel DataGuard — 增量 PII 脱敏库

对完成模板变量替换后的通知正文做流式脱敏，输出供调用方持久化。
无论输入如何切块（包括在多字节字符内部切开），最终脱敏字节与替换区间
完全一致；任何已返回的字节都不需要撤回或修正。

## 识别规则

- 匹配视图：全角数字→ASCII 数字，U+FF0D→`-`，U+00A0→空格；其余字符不变。
- SSN：`DDD-DD-DDDD`（不检查号码分配规则）。
- 银行卡号：13–19 位数字，相邻数字间可无分隔符或有一个空格/连字符，
  去分隔符后须通过 Luhn 校验。
- 命中左右紧邻字符均不得为数字；正文边缘视为满足。
- 所有满足规则的区间（含短候选、嵌套、跨类型交叠）合并后整体替换为
  `[REDACTED]`，每个合并区间只报告一次；未覆盖的原始字节逐字节保留。

## 使用

```python
from sentinel_dataguard import Masker

masker = Masker()
safe, intervals = masker.feed(b"call 123-45-6789 now")
# safe == b"call " 之前缀与后续安全字节（可能因 128 码点延迟而暂时为空）
tail, tail_intervals = masker.finish()
# safe + tail == b"call [REDACTED] now"
# intervals + tail_intervals == [(5, 16)]  （原始输入字节流的绝对偏移，左闭右开）
```

- `feed(data) -> (bytes, [(start, end), ...])`：返回本次产生的安全字节
  及已确定结束的替换区间。
- `finish() -> (bytes, [(start, end), ...])`：输入结束，返回剩余结果。
  各次返回字节顺序拼接为完整结果；区间按顺序连接为完整替换清单。

## 资源保证

- 内部未决原文最多 112 个码点（≤ 448 字节 < 512 字节上限）。
- 未命中文本最多延迟 112 个码点输出（< 128 码点上限）。
- 连续交叠命中可形成任意长的合并区间，内存仍有界（区间内容即时丢弃，
  仅记录起止偏移）；不缓存完整正文、不写临时文件。
